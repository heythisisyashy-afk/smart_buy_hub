SMARTBUY HUB — STARTER WEBSITE

This is a Google Apps Script web app, not a standalone HTML file. It needs to be installed in a Google Apps Script project linked to a Google Sheet.

Start with SETUP.md. The website has a responsive catalogue, search, category filters, cart, customer details form, order confirmation, optional WhatsApp follow-up, and Google Sheets order logging. Export the sheet to .xlsx for Excel.
